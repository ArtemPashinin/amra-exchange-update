# AMRA Exchange Update

Сервис для автоматического обновления курсов обмена валют и криптовалют в базе данных.

## Кратко о приложении

`amra-exchange-update` — это backend‑процесс, который:
- регулярно забирает рыночные курсы из внешних API;
- применяет бизнес‑комиссии (спред/fee);
- сохраняет итоговые курсы обмена в MySQL;
- предоставляет endpoint для получения курса по валютной паре.

## Зачем нужен проект

Проект нужен, чтобы поддерживать **актуальные обменные курсы** в собственной системе (касса/обменник/платежный контур) без ручных обновлений. Это снижает риск устаревших цен и упрощает работу других сервисов, которые читают курсы из БД.

## Что делает сервис

- По cron-задаче (каждые 30 секунд) запускает обновление всех поддерживаемых направлений.
- Обновляет курсы для направлений с участием: `USDT`, `USD`, `RUB`, `ETH`, `BTC`, `AED`, `TON`, `EUR`.
- Считает обратные курсы и применяет комиссии из конфигурации `Fee`.
- Пишет курсы в таблицу обменов через Sequelize модели.
- Отдает данные по endpoint:
  - `GET /course/:id?` — получить курс относительно RUB (по id исходной валюты).

## На базе чего работает

Сервис строится на двух источниках рыночных данных:

1. Внешний API стакана/офферов (`API_URL`) — используется для пар вроде `USDT/RUB`, `BTC/USD`, `ETH/RUB` и т.д.
2. Отдельный API для TON (`TON_API_URL`) — используется для получения мультивалютных курсов TON/USD/RUB.

Далее данные обрабатываются внутри приложения (с учетом комиссии) и сохраняются в MySQL.

## Технологический стек

- **Node.js** + **TypeScript**
- **NestJS 10** (модули, DI, HTTP, контроллеры)
- **@nestjs/schedule** (cron-задачи)
- **Axios / @nestjs/axios** (запросы во внешние API)
- **Sequelize + sequelize-typescript + @nestjs/sequelize**
- **MySQL (mysql2)**
- **Jest** (тестирование)
- **ESLint + Prettier** (линтинг и форматирование)

## Переменные окружения

Минимально необходимые переменные:

- `HOST` — хост MySQL
- `DBUSERNAME` — пользователь MySQL
- `PASSWORD` — пароль MySQL
- `DATABASE` — имя БД
- `SYNCHRONIZE` — синхронизация схемы Sequelize (`true/false`)
- `API_URL` — базовый URL API офферов
- `TON_API_URL` — базовый URL API курсов TON
